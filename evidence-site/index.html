独立性保证

独立实现可以读上游源码与 spec 来推导规则，但绝不 import、exec、eval 或执行上游代码。

# 四个脚本统一检查：禁止 import 上游包
$ grep -nE "^import agent_evidence|^from agent_evidence" independent_*.py
# → 无任何输出（CLEAN）
只读源码 / spec 推导规则

不 import、不 exec、不 eval、不复制执行上游任何代码。

裁决只来自原始字节

每个判断从 test-case / statement / store 的原始字节得出。

expected 仅事后对比

MANIFEST 的期望结果不参与裁决，只在裁决完成后核对。

信任起点 cosign.pub

Ed25519 公钥来自 release/cosign.pub；底层原语 JCS / PAE / Merkle / strict-b64 / I-JSON 全部从零重写。
